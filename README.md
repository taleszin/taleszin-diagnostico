# Taleszin Diagnóstico

App estilo CPU-Z, didático: CPU (com estimativa de aquecimento), memória, bateria, armazenamento, rede, tela/GPU, sensores, câmera, sistema e saúde (lê a telemetria da ROM). Java puro, minSdk 19, ~7 MB de RAM.

Build: `./build.sh` → `build/diagnostico.apk`.

Parte da [Taleszin OS](https://github.com/taleszin/taleszin-os), ROM autoral para o tablet Multilaser M7s Dual Core (RK3026, Android 4.4). Licença MIT.
